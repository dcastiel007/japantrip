# Big in Japan — אפליקציית המסלול

## המטרה: קישור אחד

הנוסעים מקבלים **`https://japantrip.odysee.me`** וזהו.
הכתובת הזאת פותחת את האפליקציה. אין תיקיות, אין מה להסביר.

## איך להעלות לריפו

הריפו הזה משרת את שורש `japantrip.odysee.me`.
**האפליקציה נכנסת לשורש, והדף הישן הופך ל-`about.html`.**

1. **קודם כל: שנו את השם של הדף הקיים** מ-`index.html` ל-`about.html`.
   (או פשוט העלו את ה-`about.html` שבזיפ — הוא אותו דף בדיוק,
   בתוספת פס «חזרה לאפליקציה» למעלה.)
2. העלו את שאר הקבצים מהזיפ **לשורש**, באותה רמה:

```
/                       ← שורש japantrip.odysee.me
  index.html            ← האפליקציה  (חדש)
  about.html            ← הדף הישן   (שינוי שם)
  sw.js
  manifest.webmanifest
  icon-192.png
  icon-512.png
  icon-maskable-512.png
  apple-touch-icon.png
  CNAME                 ← לא נוגעים
```

3. זהו.
   - `japantrip.odysee.me` → האפליקציה
   - `japantrip.odysee.me/about.html` → הרקע, ואליו יש כפתור
     מתוך לשונית «מידע» באפליקציה. בכיוון ההפוך יש פס חזרה למעלה.

**למה `index.html` ולא `app/index.html`:** `index.html` הוא הקובץ
שהשרת מגיש כשמבקשים כתובת בלי שם קובץ. כדי שהקישור יהיה
`japantrip.odysee.me` נקי — האפליקציה חייבת להיות ה-`index.html`
של השורש. שני קבצים לא יכולים לשאת את השם הזה באותה תיקייה,
ולכן הדף הישן מקבל שם משלו.

**אין build, אין npm, אין תלויות.** כל הנתונים והפונטים מוטמעים
בתוך `index.html`. כל הנתיבים יחסיים.

## HTTPS

ה-service worker — מה שמאפשר עבודה בלי אינטרנט — רץ **רק על HTTPS**.
נבדק 23/08/2026: `https://japantrip.odysee.me` נטען מעל HTTPS תקין,
כלומר התעודה מכסה את הסאב-דומיין וזה ירוץ.

## מה לשלוח לנוסעים

> הנה הטיול: **japantrip.odysee.me**
> באייפון: לפתוח ב-Safari ← כפתור השיתוף ← «הוסף למסך הבית».
> באנדרואיד: כרום ← תפריט ← «התקן אפליקציה».
> אחרי זה זה עובד גם בלי אינטרנט ביפן.

**חוץ מכפתורי «מפה»**, שפותחים את Google Maps ודורשים קליטה.
כפתור «כתובת לנהג» עובד תמיד, גם במטוס.

## עדכונים

בכל גרסה חדשה משתנה מספר הגרסה בראש `sw.js`
(`const CACHE = "jp2026-v11"`). **זה מה שגורם לטלפונים למשוך את
הגרסה החדשה.** אם מעלים `index.html` חדש בלי לשנות את המספר הזה —
מי שכבר התקין ימשיך לראות את הישן.

הדף עצמו נמשך קודם מהרשת ורק אם אין קליטה מהמטמון, כך שעדכון
מופיע מיד למי שמחובר.

## מה בפנים

- **פונטים מוטמעים כ-base64:** Heebo (עברית), Sora ו-JetBrains Mono
  ממערכת המותג של Odysee. אפס בקשות ל-Google Fonts — זה מה שמאפשר
  אופליין אמיתי.
- **טוקנים:** הפלטה מ-`odysee-tokens.css` — נייבי, טרהקוטה, שנהב,
  mist. בהיר כברירת מחדל, כהה לפי מערכת ההפעלה או לפי המתג.
- `noindex` בשני הדפים.
